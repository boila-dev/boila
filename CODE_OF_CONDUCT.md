# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

By participating, you agree to uphold it.

## Enforcement

Report concerns privately via [GitHub's report abuse flow](https://github.com/contact/report-abuse) or to the maintainers through a [private security advisory](https://github.com/boila-dev/boila/security/advisories/new) (use the abuse report flow for non-security concerns).

Maintainers respond within 7 days and may take any action they deem appropriate — from a private warning to a permanent ban from the project — per the enforcement ladder in the Covenant.

## Scope

Applies to all project spaces: this repository, its issues and PRs, GitHub Discussions, and any official communication channel.
